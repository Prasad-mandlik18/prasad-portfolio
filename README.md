## 🌟 Overview

A modern, high-performance portfolio engineered with **React**, **TypeScript**, **Tailwind CSS v4**, and interactive **21st.dev** generative UI components. Designed to showcase production AI architectures, dense vector retrieval systems, and full-stack software.

### 🚀 Key Interactive Highlights

- 🌀 **Living Data Physics Backdrop (`DataRain`)**: A custom canvas engine running divergence-free wave harmonics, vortex shedding, and interactive cursor dynamics with real-time speed regulation.
- 🎡 **3D Interactive Project Wheel (`WorksWheel`)**: Immersive 3D drum perspective carousel written directly to DOM transforms via `requestAnimationFrame` for 60 FPS rotation and touch/drag gestures.
- 🧠 **End-to-End System Pipelines**: Visual dataflow diagrams on every project detailing preprocessing, embedding models, vector indices, and inference fallbacks.
- 🎯 **Interactive Tech Matrix**: Live skill filter chips that highlight where technologies are applied across real-world systems.
- 📄 **Curriculum Vitae Modal & Download**: Instant modal preview with celebratory confetti effects and one-click CV export.

## ⚡ Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# 1. Clone repository
git clone https://github.com/Prasad-mandlik18/prasad-portfolio.git
cd prasad-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
